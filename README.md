Developed an end-to-end AI-powered voice assistant using Python, Faster-Whisper, Ollama (Llama 3.2), and Piper TTS, enabling natural voice interactions through locally hosted AI models. Implemented a complete speech-to-speech pipeline with 5-second audio recording intervals at a 16 kHz sampling rate, CPU-based speech recognition, LLM inference, and voice response generation. Integrated two custom tools for real-time clock queries and mathematical calculations using JSON-based function routing. Optimized speech recognition for CPU execution using INT8 quantization, reducing model memory requirements compared with higher-precision inference. The application supports continuous voice interactions and demonstrates local AI deployment without cloud-based LLM APIs.
